# Surendra Kumar - Portfolio Website

This is my personal portfolio website showcasing my projects, skills, and professional experience.

## Features

- Modern, responsive design
- Project showcase with images and descriptions
- Work experience timeline
- Skills and technologies section
- Contact information and social links
- Resume download

## Technologies Used

- Next.js 
- React
- TypeScript
- Tailwind CSS
- React Icons

## Running Locally

First, clone the repository:

```bash
git clone https://github.com/surendrakumar6350/portfolio.git
cd portfolio/v3
```

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This site is built to be deployed on Vercel or any platform supporting Next.js.
